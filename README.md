# Ghidra 12.1.4 Workspace

Public, already-extracted Ghidra 12.1.4 workspace intended for ChatGPT Work / Linux environments.

## Clone

```bash
git clone --depth 1 https://github.com/Chaborsz/Ghidra-12.1.4-Workspace.git
```

Ghidra is directly available at:

```text
Ghidra-12.1.4-Workspace/ghidra_12.1.4_PUBLIC/
```

Headless analyzer:

```text
ghidra_12.1.4_PUBLIC/support/analyzeHeadless
```

Ghidra requires JDK 21.
